Global Risk Management and Anomaly Detection Pipeline

Architected an enterprise-scale data ingestion pipeline using Azure Databricks and a Medallion Architecture to feed multiple Risk Management Systems, process global balance sheets, and detect trade anomalies.

Overview

In the banking sector, consolidating front-to-back system data for multiple Risk Management Systems (RMS) is a massive data engineering challenge. The bank required a unified, highly scalable platform to ingest massive daily transaction files, manage the global balance sheet, and apply intelligent rules to detect anomalies in real-time trades.

I spearheaded the design and implementation of an Azure Databricks pipeline utilizing the Medallion Architecture. By standardizing the ingestion flow and packaging the processing logic into modular Python Wheel files, we enabled multiple RMS pipelines to operate independently while feeding into a governed, centralized Gold layer in Unity Catalog.

Architecture Highlights

  • Medallion Data Architecture: Implemented a strict Bronze (raw data), Silver (cleansed & filtered), and Gold (business-level aggregations) pattern to ensure data quality and auditability for financial regulators.
  • Azure Integration: Transaction and trade files are continuously placed into an Azure Data Lake Storage (ADLS) account, triggering automated ingestion workflows.
  • Databricks Workflows & Python Wheels: Each RMS operates its own Databricks pipeline. Complex transformation logic is packaged into deployable Python Wheel files, ensuring version-controlled, reusable, and testable codebase execution.
  • AI/ML Anomaly Detection: Applied machine learning rules on top of the Silver/Gold layers to proactively detect anomalous trading patterns and flag them for risk analysts.
  • Unity Catalog: Enforced strict data governance and fine-grained access control on the Gold layer, ensuring that highly sensitive global balance sheet data is securely managed across different business domains.

Outcomes

  • Unified disjointed legacy ingestion systems into a single, highly performant Databricks platform, drastically reducing data engineering overhead.
